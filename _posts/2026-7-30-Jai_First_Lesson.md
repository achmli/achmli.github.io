### 程序目标

实现一个命令行整数数据分析器。

给定一组整数，输出：

- 元素总数；
- 总和；
- 最小值；
- 最大值；
- 平均值；
- 正数、负数和零的数量。

### 程序代码喵

```jai
#import "Basic";
#import "Random";

array_analyzer :: (values: [] $T) {
    print("Type of Elements is %\n", T);
    
    print("Count of elements: %\n", values.count);

    if values.count == 0 {
        print("empty input.\n\n");
        return;
    }

    sum: T = 0;
    min_val: T = values[0];
    max_val: T = values[0];
    pos_count: u32 = 0;    // 实际上用s64会更好，因为数组的count成员是s64
    neg_count: u32 = 0;
    zero_count: u32 = 0;

    for values {
        sum += it;

        if it < min_val min_val = it;
        if it > max_val max_val = it;

        if it > 0 {
            pos_count += 1;
        } else if it < 0 {
            neg_count += 1;
        } else {
            zero_count += 1;
        }

        print("% ", it);
    }

    print("\nsum is %, and the type of sum is %\n", sum, type_of(sum));
    print("the minimum is %, and the type of minimum is %\n", min_val, type_of(min_val));
    print("the maximum is %, and the type of maximum is %\n", max_val, type_of(max_val));
    print("the count of positive numbers is %\n", pos_count);
    print("the count of negative numbers is %\n", neg_count);
    print("the count of zeros is %, type of the count is %\n", zero_count, type_of(zero_count));

    average: float64 = 0.0;
    average = cast(float64) sum / cast(float64) values.count;
    print("average of the numbers is %, type of average is %\n\n", average, type_of(average));
}
    
main::() {
    nums: [..] s32;
    defer array_free(nums);
    for 1..(cast(s32) random_get_within_range(10.0, 20.0)) {
        array_add(*nums, cast(s32) random_get_within_range(-50.0, 50.0));
    }

    values1 := s64.[1, 2, 3, 4, 5, 6];
    values2 := s32.[-1, -2, -3, -4, -5, -6];
    values3 := s32.[0, 1, -2, 3, -4, 5, -6];
    values4 : [] s64;
    values5 := u32.[42];
    values6 := s64.[5000000000, 20000000000];
    values7 := s32.[-42];

    array_analyzer(nums);
    array_analyzer(values1);
    array_analyzer(values2);
    array_analyzer(values3);
    array_analyzer(values4);
    array_analyzer(values5);
    array_analyzer(values6);
    array_analyzer(values7);
}
```

这样写是错的，也是这节课的关键内容喵，`::`和`:=`的差别是什么。之前看得不是很仔细，所以以为这两个是等价的。但实际上`::`声明的是常量，而`:=`声明的是变量喵。那为什么是常量就不能这样赋值了呢，因为是编译期常量，必须在编译期间确定值，而这个函数是运行时随机过程，不能在编译期确定结果，所以会报错。

### 关键语法

+ `:`、`:=`、`::`：变量声明、类型推导和编译期绑定；
+ `=`、`+=`：初始化、赋值与复合赋值；
+ `cast`：显式数值转换；
+ `type_of`：获取表达式类型；

### 与C++的主要差异

+ C++似乎从C++ 11开始才有了用来自动推导类型的`auto`关键字，而jai从一开始就有类型推导，还不用auto这种关键字。
+ jai中的类型声明使用的符号是`:`，而cpp是把类型关键字写在变量前（这种语法上的差异真的有必要写吗，而且单说声明不说赋值，难道cpp很多样吗）。
+ jai中声明浮点数，不用在末尾加f喵。
+ 对比cpp中`int32_t`这种精确表达位宽的类型名是别名，而不是类型原本的名称（不想具体展开吐槽cpp，我是在学jai而不是rust，不需要靠吐槽cpp来获得继续学习的动力捏），但是在jai中是反过来的，`int`反而是`s64`的别名（实际上UE里也强制写位数，不让用本命，名可名，非常名这一块嗷，所以估计这么写就是比较游戏吧）。
+ 对比C/C++的传统c风格的`printf`，需要在string中用`%d`之类的，不仅占位，还要背类型，而jai的print，所有的输出占位都是`%`，十分方便。
+ jai的`int`是64位有符号整数，但是`float`的确是32位浮点数.
+ 就先这样吧，学会更多再补充。

原本是数据和内存所有权，显然不是现在能回答的，甚至考虑到内存分配的复杂程度，估计要有调试工具才能做出十分准确的回答。

但是回到数据的生命周期，这就不是一个不能回答的问题了。

`array_analyzer`中创建了一些局部变量，比如`sum`、`min_val`、`pos_count`等，不考虑内存分配到什么地方，在函数执行完成并返回之后，这些局部变量名称和对应的状态也就不再能使用。

`main`中创建了两种类型的数组：像`values1` ~ `values7`那样的固定数组（还有一个空数组slice，但说实话也没那么重要，这是入门课程的第一个学习程序，不需要很高的超出课程内容的严谨性，即使把空数据去了也不会有什么严重后果）和像`nums`那样的动态数组。其中固定数组，在传入`array_analyzer`后，`array_analyzer`获得的是这段数组数据的一个slice视图，可以用来读取这段数据，但没有取得数据的所有权，也不负责释放它。数组仍然由`main`中的原始局部值管理。

#### 理解`:`、`:=`和`::`的区别。

`:`就是用来声明喵，比如`a: s64`和`a: s64 :10`，虽然后者看上去也负责了初始化，但是毕竟这也是一种声明的形式捏，是声明一个显式类型的编译期绑定喵。像`a: 10`是不行的，也就是`:`事实上确实只能用于声明捏。

当然`:=`和`::`也是用来声明而非赋值的，只是它们不需要写类型名，也就是会自动推导类型。所以这两个操作符就是在省略类型的时候使用的，正常的声明是`a: typename: value`或者`a: typename = value`，只是省略了typename所以写成这种形式。这两者的差别就是`::`声明的是编译期常量，而`:=`声明的是变量。难道说是因为常量不可变，所以`:`不能单独用于赋值喵？当之然这不是正确的原因，`::`声明的值基本上等效于字面量，无论如何都不可能把`114514`赋值成`1919810`是吧。

不过太过常用以至于反而忽视了喵，声明函数用的也是`::`，总而言之，ai大人说了：它把名称绑定到编译期已知的值、过程、类型或模块。

#### 理解显式类型、类型推导和编译期常量

实际上感觉上一条已经说了一部分了。显式类型就是在声明时写了类型名，顺便在jai中`int`是`s64`的别名，`float`是`float32`的别名。

类型推导，不考虑实现，虽然在how_to中，吹哥很认真的用AST来解释了，但我确实不懂编译这一块。但是就只考虑效果的话，`10`、`114514`之类的整数给变量赋值时，变量会默认被声明为64位有符号整数，也就是`s64`，也就是不能出现`a:=10; b: u8 = a;`这样的情况。但是`a::10; b:u8 = a;`是允许的，不是把a重新推导成了u8（真会有人这么想吗），只是u8表示10不会溢出，所以编译器允许这样初始化和赋值。相比之下，`a := 10`声明的是一个真正的运行时`s64`变量，Jai不会仅仅因为它当前的值碰巧是10，就允许它隐式缩窄为`u8`喵。然后`114.514`、`1919.810`之类的浮点数会默认声明成`float32`，不过如果精度明显超过`float32`的情况编译器也会选择默认声明成`float64`。

然后像`a: s32 = 325; b:= a;`这种情况，就是根据用来赋值的变量的类型来声明被赋值的类型，也就是`b`也是`s32`。

说到编译期常量，`: typename :`、`::`的编译期常量绑定的概念和cpp的`constexpr`关键字更加接近，而不是主要表达只读访问语义的`const`。

`type_of`大概和这个部分也算有关系吧。`type_of`返回的并非`string`之类的，返回的就是类型`Type`值，就是类型本身，jai 中，类型本身可以作为值保存、比较和传递捏。

#### 熟悉 Jai 的整数和浮点类型

感觉前面讲得差不多了，具体的类型应该就是`s8`、`u8`、`s16`、`u16`、`s32`、`u32`、`s64`、`u64`、`float32`、`float64`。

#### 理解 Jai 为什么尽量统一声明语法

不理解喵，真的统一了吗。。。。在第一节就用涉及这种设计哲学层面的东西感觉不太合适喵。

毕竟我也不是cpp高手喵。

但是ai大人让我这么写喵：Jai 所谓统一声明语法，是指变量、常量、过程、类型和模块名都采用“名称在前、声明信息在后”的形式，而不是分别发明完全不同的声明关键字和语法。:= 与 :: 也可以看作完整声明形式在省略类型后的自然结果。
